# Agent Instructions

Always read `./CLAUDE.md` before doing any project work in this repository.

Treat `CLAUDE.md` as required repository-level agent instructions for every
task. It defines the project's standard workflow, Makefile commands, validation
gates, CSS/SVG rules, deployment rules, and local conventions. Follow those
instructions the same way you would follow this file.

If a future subdirectory adds its own `CLAUDE.md`, read that more-specific file
as well before changing files under that subtree. More-specific local guidance
extends the root `CLAUDE.md`; it does not replace the root file unless it says so
explicitly.
