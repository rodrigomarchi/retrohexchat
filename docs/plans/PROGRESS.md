### ⚠️ Anti-padrões aprendidos (checar ANTES de migrar)
1. **Modal-in-modal com input não-controlado** (grep `fixed inset-0` no UI + `<input>`/`<.input>` sem `value`): submeter ao parent de dentro do componente quebra a preservação de valor → input some no re-render. Ocorre em **41 (bloqueado), 30, 31, 35**. Use input controlado, `phx-update="ignore"`, ou sub-forms OWNED (`@myself`).
2. **`render_submit` + `JS.push(value:)`** não despacha sob LiveViewTest → use hidden input + `phx-value` + evento STRING.
3. **`git checkout <file>`** com trabalho não-commitado = perda total no arquivo. Nunca usar para desfazer edições; recuperar via `git fsck --no-reflog`.
